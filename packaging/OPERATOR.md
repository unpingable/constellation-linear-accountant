# Linear Accountant installed inference accounting

LA bounds inference expenditure for a separately admitted model consumer. It
reserves the maximum episode allocation, burns each call ceiling with a send
fence, records actual usage/cost and reconciles the milestone. It grants no
operational effect authority and refunds no consumed capacity.

This package is inert: no enrollment, budget, store or provider credential ships.
The custodian manages the root-owned store and imports its separate owner
admission. `la_inference version` identifies the native protocol/schema; its
legacy crate version0.0.0/unknown commit is distinct from this Debian artifact
revision. Use `dpkg-query -W linear-accountant-inference` and the combined
candidate's exact executable/source/hash manifest for identity.

See [native inference protocol](INFERENCE_ACCOUNTING.md) for source-defined
commands/units/refusals. Only the existing store custodian may invoke those
commands: logical `inspect`/`reconcile` still open the owned store under its
exclusive lock. Workbench receives a selected recorded disclosure, never store
permissions or budget administration. Unknown actual cost, retired allocation
and exhaustion must remain visible.

The source-free [candidate operator guide](https://github.com/unpingable/unpingable-site/blob/dev/operator-beta/constellation/combined-candidate/README.md)
contains installation, optional-v2 scope and the read-only accounting view.
V1 remains default; most workflows use no model or LA.

Before package upgrade/removal, stop its separately enrolled model consumer and
reconcile uncertain sends. Keep protected store/admission/credential custody.
Package removal does not revoke provider credentials or settle an open invocation.
